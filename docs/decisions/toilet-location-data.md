# 화장실 위치 데이터

## Decisions

- 공공화장실 데이터는 공공데이터포털의 전국공중화장실표준데이터(CSV)를 원본으로 쓴다.
- 원본에 좌표가 없으므로 전국 주소를 미리 한 번 좌표로 변환(지오코딩)해 앱 데이터로 보관한다. 접속 시점에는 주소를 변환하지 않는다.
- 전국 좌표를 얻을 길(좌표제공 API 키, 위치정보요약DB)이 확정되지 않았으므로, 지금은 좌표가 이미 들어 있는 지역별 공개 파일(서울, 경기, 제주시)을 전국 CSV와 함께 쓴다. 좌표는 지역 파일의 값을 쓰고, 전국 CSV는 전국 기준 목록과 나중에 지역을 넓힐 원본으로 유지한다.
- 좌표가 없는 지역은 "아직 지원하지 않는 지역"으로 안내한다. 지원 지역이 넓어지는 방식은 좌표제공 API 키나 위치정보요약DB가 해결될 때 전국 CSV로 스크립트를 다시 돌리는 것이다.
- 사용자에게는 현재 위치 반경 안의 장소만 보여준다. 준비하는 데이터의 범위는 목표로는 전국이고, 현재는 지원 지역으로 한정된다.
- 변환에 실패한 건은 목록에서 제외한다.
- 화면에 데이터 기준일(원본을 가져와 좌표로 변환해 둔 날)을 표시한다.
- 지도는 OpenStreetMap 타일을 쓰고, 지도 위에 저작자 표시를 눈에 띄게 둔다. 길찾기는 외부 지도 앱으로 연결한다.

## Boundaries

- 이 결정은 공공화장실 데이터와 지도 표시에 적용된다. 카페, 지하철역, 주유소, 휴게소 같은 대안 장소의 데이터 출처는 정하지 않았다.
- 지오코딩 제공사는 행정안전부 주소기반산업지원서비스의 좌표제공 API다. 이용약관의 저장 허용 여부, 응답 좌표계, 일일 한도는 아직 확인하지 않았고 구현 첫 단계에서 확인한다. 이 API는 주소 문장이 아니라 행정구역코드, 도로명코드, 건물 번호를 받으므로 주소를 코드로 바꾸는 단계가 먼저 필요하고, 건당 호출이 늘어난다.
- API 키 발급은 이 결정이 정하지 않는다.

## Why

원본(2025년 2월 이후)에서 WGS84 위도·경도 항목이 빠져, 위치 기반 정렬을 하려면 좌표를 직접 만들어야 한다. 접속 시점에 현재 지역만 변환하면 처음 접속하는 지역에서 수 초에서 십수 초(추정)를 기다려야 해서, 급한 사용자에게 약속한 "빠르게 찾기"와 맞지 않는다. 미리 변환하면 대기가 없고 일회성 작업으로 끝난다.

## Reconsider when

- 원본이 좌표를 다시 제공하기 시작할 때
- 좌표제공 API 키나 위치정보요약DB를 받아 전국 좌표를 만들 수 있게 될 때(지역 파일 의존을 줄이거나 없앨 수 있다)
- 지오코딩 제공사의 호출 한도나 약관 때문에 전국 사전 변환이 불가능하다고 확인될 때
- OpenStreetMap 타일 서버가 이 앱의 트래픽을 제한하거나 정책이 바뀔 때

## Still-rejected alternatives

- 카카오 로컬 API, 브이월드 지오코더로 변환해 저장하는 방식 — 두 곳 모두 결과 저장을 금지하는 것으로 안내된다(카카오는 담당자 답변 사례, 브이월드는 공식 안내). 약관이 바뀌어 저장을 허용하면 다시 검토한다.
- 접속 시점에 현재 시·군·구만 변환하고 저장하는 방식 — 처음 접속하는 지역의 대기가 길다(추정). 실측으로 수 초 이내임이 확인되면 다시 검토한다.
- 좌표를 직접 제공하는 지자체별 데이터만 쓰는 방식 — 일부 지역만 커버되어 전국 서비스 약속과 맞지 않는다.
- 사용자가 주소나 지역을 직접 입력해 찾는 방식 — 접속 시점에 변환이 다시 필요해진다. 위치 권한이 없는 사용자의 이탈이 크다고 확인되면 다시 검토한다.

## Evidence worth preserving

- [전국공중화장실표준데이터](https://www.data.go.kr/data/15012892/standard.do)와 [행정안전부_공중화장실정보](https://www.data.go.kr/data/15075531/fileData.do)는 약 52,000건이고 개방시간을 포함하며 CSV로만 제공된다. 두 페이지 모두 WGS84 위도·경도 제외를 안내한다(2026-10-22 확인).
- 지오코딩 제공사 비교(2026-10-22): [카카오 데브톡](https://devtalk.kakao.com/t/local-api-geocoding/151848)은 배치 변환 후 DB 저장을 정책상 금지라고 답한 사례, [브이월드](https://www.data.go.kr/data/15101106/openapi.do)는 저장 금지와 일일 3만～4만 건 한도, [좌표제공 API](https://www.data.go.kr/data/15057559/openapi.do)는 이용허락범위 제한 없음과 자동승인이다.
- [OpenStreetMap 타일 정책](https://operations.osmfoundation.org/policies/tiles/): 사용자가 보는 화면 분의 타일 요청은 허용, 대량 다운로드와 프리페치는 금지, 저작자 표시 필수, 가용성 보장 없음(2026-10-22 확인).
