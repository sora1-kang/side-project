# 공공화장실 찾기

## 사용자가 얻는 결과

화장실이 급한 사람이 페이지를 열면, 현재 위치 기준으로 가까운 공공화장실이 지도와 목록에 바로 나타난다. 원하는 곳을 골라 외부 지도 앱의 길찾기로 이동할 수 있다.

앱 전체 전제는 루트 `PRODUCT.md`를 따른다. 이 작업은 그중 첫 단위로, 이동 방식(보행 중, 주행 중) 선택, 카페, 지하철역, 주유소, 휴게소, 평점과 후기는 포함하지 않는다.

## 범위

- 페이지를 열면 위치 권한을 요청하고, 허용되면 현재 위치 반경 안의 공공화장실을 보여준다.
- 지도와 목록을 함께 보여준다.
  - 지도에는 현재 위치와 공공화장실 핀을 표시한다.
  - 목록은 가까운 순이다. 항목을 고르면 지도의 해당 핀이 강조된다.
  - 좁은 화면에서는 지도 아래에 목록을 쌓는다.
- 탐색 반경을 사용자가 바꿀 수 있다.
- 각 항목에서 외부 지도 앱의 길찾기로 연결한다.
- 화면에 데이터 기준일을 표시한다.

## 수용 기준

1. 위치 권한을 허용하면 별도 조작 없이 반경 안의 공공화장실이 지도와 목록에 나타난다.
2. 목록은 현재 위치에서 가까운 순으로 정렬되고, 최대 20곳을 보여준다.
3. 각 항목은 이름, 현재 위치에서의 거리, 주소, 개방시간, 길찾기 버튼을 보여준다.
4. 목록 항목을 고르면 지도의 해당 핀이 강조된다.
5. 반경의 기본값은 500m이고, 사용자가 100m에서 5km 사이에서 바꿀 수 있다. 바꾸면 목록과 지도가 새 반경에 맞게 갱신된다.
6. 길찾기 버튼을 누르면 해당 장소로의 길찾기를 외부 지도 앱에서 연다.
7. 반경 안에 공공화장실이 없으면 없다는 사실을 알리고, 반경을 넓히도록 안내한다.
8. 위치 권한을 거부했거나 위치를 얻지 못하면, 이유와 권한을 다시 요청하는 방법을 안내한다. 주소나 지역을 직접 입력하는 기능은 없다.
9. 화면에 데이터 기준일이 보인다.
10. 지도 위에 "© OpenStreetMap contributors" 저작자 표시가 눈에 띄게 보인다.
11. 현재 위치에서 가장 가까운 데이터가 10km보다 멀면 "아직 지원하지 않는 지역입니다"를 보여주고, 반경 안내(7번)는 보여주지 않는다.

## 지원 지역 (임시)

전국 좌표를 얻을 길이 아직 확정되지 않아, 처음에는 좌표가 이미 공개된 지역(서울, 경기, 제주시)만 지원한다. 지원하지 않는 지역에서 연 사용자에게는 "아직 지원하지 않는 지역입니다"라고 알리고, 이 안내는 "반경 안에 화장실이 없음"과 구분되게 보여준다. 전국 좌표가 해결되면 이 절은 사라지고, 이 임시 동작은 그때 결정으로 대체된다. 근거는 [toilet-location-data](../../decisions/toilet-location-data.md)가 가진다.

## 확정된 제약과 이유

- 데이터는 전국공중화장실표준데이터를 원본으로 하고, 좌표는 미리 변환해 둔 값을 쓴다. 접속 시점에 주소를 변환하지 않는다. 변환에 실패한 건은 목록에서 제외한다. 이유와 재검토 조건은 [toilet-location-data](../../decisions/toilet-location-data.md)가 정한다.
- 지도는 OpenStreetMap 타일을 쓰고, 길찾기는 외부 지도 앱으로 연결한다. 같은 계약이 근거를 가진다.
- 화면 구성은 [ui-composition](../../decisions/ui-composition.md)을 따른다. 지도는 이 앱의 핵심 표면이라 직접 구현할 수 있고, 그 안의 일반 control과 안내, 상태 표시는 공식 component 구성을 유지한다.
- 급한 사람이 기다리지 않도록, 위치가 확인되는 즉시 결과를 보여주는 속도를 지킨다(`PRODUCT.md`의 경험 원칙).
- 로딩, 결과 없음, 위치 권한 거부 및 오류 상태를 정상 화면과 같은 문법으로 설계한다.

## 가정 (바꾸고 싶으면 말해 주세요)

- 반경 기본값 500m, 범위 100m～5km.
- 목록 항목 구성(이름, 거리, 주소, 개방시간, 길찾기)과 최대 20곳.
- 데이터 기준일은 공공데이터를 가져와 좌표로 변환해 둔 날을 뜻한다.
- 길찾기는 카카오맵 링크(`map.kakao.com/link/to/...`)로 연다. 키가 필요 없고 모바일에서는 앱으로 이어진다.
- 지원 지역인지는 가장 가까운 데이터가 10km 안에 있는지로 판단한다. 지역 경계를 따로 두지 않으므로, 지원 지역 가장자리 밖(예: 인천 일부)은 지원 지역으로 보일 수 있다.
- 지역 파일의 개방시간 값 중 의미 없는 값(빈 값, ":~:", "정시", "불규칙", "기타", "정시(영업시작~종료)")은 "정보 없음"으로 보여준다.
- 전국 CSV에서 간이화장실, 이동화장실, "미개방" 건은 제외하고, 지역 파일의 간이·이동 화장실도 제외한다.
- 개방시간은 원본 값을 그대로 보여준다. 지금 열려 있는지 판정하지 않는다.

## 범위 밖

- 이동 방식 선택, 카페, 지하철역, 주유소, 휴게소: 이후 작업 단위에서 다룬다.
- 평점과 후기: 이후 작업 단위에서 다룬다.
- 주소나 지역 직접 입력 검색: 위치 권한이 없는 사용자는 이번에 쓸 수 없다.
- 지도 안의 길안내: 외부 지도 앱에 맡긴다.

## 보류한 항목

- 지오코딩 제공사는 행정안전부 주소기반산업지원서비스의 좌표제공 API로 정했다. 구현 첫 단계에서 다음을 확인하고, 하나라도 막히면 [toilet-location-data](../../decisions/toilet-location-data.md)의 재검토 조건에 따라 방향을 다시 정한다.
  - 이용약관이 변환 결과 저장을 막지 않는지
  - 응답 좌표계가 위경도인지, 투영좌표라 변환이 필요한지
  - 일일 호출 한도가 전국 약 52,000건 처리에 충분한지
  - 좌표제공 검색 API는 주소 문장이 아니라 행정구역코드, 도로명코드, 지하 여부, 건물 본번·부번을 받는다. 화장실 원본에는 주소 문장만 있으므로, 같은 서비스의 주소정보 검색 API로 코드를 먼저 얻을 수 있는지, 그러면 건당 호출이 두 번(약 10만 건)이 되어도 한도가 충분한지, 주소 매칭 성공률이 충분한지
  - API 키는 [주소기반산업지원서비스](https://business.juso.go.kr/jst/jstAddressApiList)에서 사용자가 직접 발급한다. 키는 API마다 따로 필요하고 개발용 키는 만료될 수 있다. 변환 작업은 일회성이다.
- 개방시간 원본의 표기 형식: 실제 CSV 헤더와 값을 확인한 뒤 보여주는 방식을 다듬는다. 그 전까지는 원본 값을 그대로 보여준다(임시).

## 남은 위험

- 지오코딩 제공사의 호출 한도나 약관 때문에 전국 사전 변환이 막힐 수 있다. 한도는 아직 확인하지 않았다.
- 주소가 부정확한 건은 변환에 실패해 목록에서 빠진다. 빠지는 비율은 아직 모른다.
- OpenStreetMap 타일 서버는 가용성 보장이 없고 정책이 바뀔 수 있다. 접근이 막히면 지도가 보이지 않는다.
- 원본이 매일 갱신되지만 앱 데이터는 기준일 시점에 고정된다. 신설, 폐쇄된 화장실이 반영되지 않을 수 있다.
